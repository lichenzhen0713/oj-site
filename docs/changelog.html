版本日志

版本号与 package.json 一致，系统设置页右上角显示当前版本，点击「版本日志」可回到本页。

完整版本线：v0.1.0 → v0.7.0（v1.0.0 之前的历代版本，编号按改动大小重新分配）→ v1.0.0 → v2.9.1（当前线）。

近期重点

  • v2.7.0：板块与分类后台自行管理
  • v2.6.x：安装体验、清理工具、评测设置、提交筛选、数据重置
  • v2.5.x：安全加固、交互题、测试点级限额、默认演示题
  • v2.4.x：题目编辑器改版、交互题持续完善
  • v2.3.x：系统设置独立成页、按钮与图标统一
  • v2.2.x：按页面设置宽度、排行榜改版

v2.9.0 #

  • 体验优化 首页加载更流畅，减少后台积分结算对访问的影响；自动积分结算降低频率，不再频繁全量计算拖慢网站；后台“立即结算”不受影响。首页不再预加载不必要的公式资源，打开更快。
  • 功能与显示 社区管理恢复为公开页：未登录也能查看，入口对所有人显示，标题统一为“社区管理”；提交详情、顶部横幅、提交记录列表的“用时”统一为各测试点用时之和，标签仍显示“用时”；无有效明细或特殊情况时，用时按回退规则显示，编译错误等显示“—”。
  • 修复 修复更换 Logo 后页面不更新；Logo 保留原设计并微调，图标与站名比例更协调，仍可手动调整；修复暗黑模式下首页副标题重影、代码框出现浅色底块；删除通信题提交详情中多余的复制按钮，保留原有复制按钮；自更新写入失败时提示更清楚，便于排查权限、只读等问题。
  • 首页快捷入口更好看：入口卡片统一等宽等高，图标改为统一尺寸的圆角底块（底色取各入口自己的主题色淡色），悬停轻微上浮并高亮描边；暗黑模式重新配色、不再透出浅色底块，窄屏两列依旧整齐、不横向溢出。

v2.8.6#

  • 修复默认网站图标"改了也不生效"：根因是默认图标的地址一直是同一个 URL，浏览器（Chrome/Edge 的图标缓存）不会重新下载，于是本机一直显示很早以前的空白图标。现在默认地址带上版本号（/api/favicon?v=…），换图标后浏览器会重新取；并新增 /favicon.ico 兜底（以前是 404），老标签页、书签、以及"没有可用图标"的场景也能拿到图标。
  • 站点 Logo 换为新图标：采用新的矢量站点图标（代码括号 + AC 对勾 + 三个测试点，渐变配色）；侧边栏、首页与浏览器标签页三处统一使用它。之前上传过的自定义 Logo 已被清除，如需再换可在「系统设置 → 网站外观」重新上传。

v2.8.5#

  • 「积分计算」改为「功能设置」的二级页面：在「系统设置 → 功能设置」页顶部新增「积分计算」入口，点进去是独立页面（面包屑「功能设置 / 积分计算」，父项「功能设置」一键可回）；旧地址会自动跳转到新地址，不留死链。页面功能不变（实时 / 定时自动 / 手动结算、间隔小时·天、状态信息、立即结算）。
  • 修复网站图标（favicon）的默认图标：原来的默认图标只是一段依赖 emoji 字体的文字，没有矢量图形——在缺少该字体的环境里会显示成空白，且没有固有尺寸、图形右侧还会被裁掉。现改为纯矢量画的天平图标（零字体依赖、自带 64×64 尺寸、不再裁切）。未上传图标、图标文件损坏、以及点「恢复默认」时，都会正确显示这个默认图标。
  • 通信题 / 交互题未配置子任务时也显示「总用时」：以前只有配置了子任务才看得到用时；现在这类提交详情里同样会显示总用时与测试点数量（数值与提交列表、横幅同源）。
  • 提交记录里的所有代码都提供复制按钮：普通题的一份代码、通信题的两份程序、交互题以及编译信息等代码块，都有统一的复制按钮（复制内容与代码完全一致）。

  • 收尾与一致性：统一各设置页的排版、只读字段与提示文案；修正若干细节（长内容输入框只读、页面标题完整、结算设置独立页面）。
  • 判题语义回归：普通题、IO 交互题、函数式交互题、通信题四类题型均回归通过（各类型保留最近一次 Accepted 记录）。

v2.8.3#

  • 已处理的反馈可以「再次处理」：后台反馈审核里，已处理 / 已关闭的反馈也能再次处理（按钮为「再次处理」，弹窗会预填上次的回复与状态）；系统会记录处理次数与上一次的处理人，便于追溯。
  • 处理反馈时通知提交者：每次处理（含二次处理）都会给提交者发一条站内通知，内容含反馈标题、处理状态、处理人与回复摘要，点击可回到反馈页。首次通知与"再次处理"通知分别标注，便于区分。

  • 「全站积分结算」独立成二级页面：从「功能设置」里移出，改为「系统设置 → 积分结算」独立页面，排版与站内其它设置页一致（不再"混在功能设置里显得突兀"）。模式（实时 / 定时自动 / 手动结算）、定时间隔（小时 · 天）、状态信息与「立即结算全站积分」按钮均照旧可用。

v2.8.1#

  • 修复页面标题被清空：此前加载站点名称后，浏览器标签页标题会被改成只剩站点名（例如「系统设置 - 站点名」变成「站点名」）；现在会保留当前页面标题，标题始终完整。
  • 「邮箱与验证」里的授权码（SMTP 密码）一直显示：取消"留空表示保持已保存的授权码不变"的做法 —— 打开设置页就能看到已保存的密码，直接修改即可；清空表示不使用密码。修改过程中不会误把密码写成占位符。

v2.8.0#

  • 支持自定义网站图标（favicon）：在「系统设置 → 网站外观」上传自己的图标（支持 PNG / JPEG / SVG / ICO / WEBP，≤512KB，校验文件头），浏览器标签页图标会即时更新；可一键「恢复默认」。未上传或文件损坏时自动回退站点默认图标（不会出现"图标 404"）。
  • 每个测试点的评测时间默认按「题目时限 × 1.2」计算：给机器抖动留出余量；可在「系统设置 → 评测设置」里调整系数（1.0 ~ 3.0，步进 0.05，默认 1.2）。单个测试点若单独配置了时限，仍以该配置为准；内存限制不受此系数影响；总评测预算同口径计算，避免"单点放宽但总预算先到"。
  • 修复：全站积分结算在遇到数据库繁忙时会整批丢失的问题（现在对 database is locked 做指数退避重试），并修正"失败批次被计入成功数"的计数错误。

v2.7.9#

  • 后台「功能开关」更名为「功能设置」，图标改为齿轮，更贴合"设置"的含义。
  • 新增「全站积分结算」（功能设置内）：可选 实时（默认） / 定时自动 / 手动结算；定时间隔以小时或天为单位（1 小时 ~ 30 天）；结算会把全站积分写入快照，并在后台显示上次结算时间、耗时与覆盖人数。
  • 新增「通信题」题型：选手提交两个程序合作完成任务，支持管道直连与评测端中转两种方式；编译错误会指明是哪一个程序，并支持特殊评测与单测试点时限 / 内存。
  • 修复通信题与特殊评测组合时可能被误报为「System Error」的问题。
  • 提交页在「自动识别语言」下也会显示 O2 优化状态；题目某个样例没有输入或输出时不再显示空框。
  • 细节完善：编译错误的测试点方块与判定文字同色；折叠侧边栏顶部与导航项对齐、折叠按钮图标在收起/展开时保持一致；题目重判页的表单排版统一。

v2.7.8#

  • 改良文章（题解 / 专栏）的社区贡献分：单篇上限由 8 分提到 12 分（计入社区系数后单篇最多 19.2 分）；短文章的"篇幅折减"从最低 30% 放宽到 60%，多篇递减系数由 0.1 放缓到 0.05。这样"写得多"与"写得长"都能得分，不会再出现"文章更多但社区分更少"的情况。
  • 点赞 / 讨论 / 回复每次最多加 1 分（此前一个讨论帖最多可加 3.2 分），避免用少量互动把社区分快速推高。
  • 比赛分要等结算：Rated 比赛在管理员完成「计算等级分」之前不计入比赛分；不评等级分的比赛不受影响。
  • 文章广场默认只显示专栏文章：点「题解」分类才显示题解，并且可以在该分类下按题号筛选某道题的题解。
  • 「写文章」页也可以直接选择「题解」分类（选中后需填写关联题目）。
  • 新增《积分系统说明》文档（站内「使用说明」目录内可打开），完整列出四维积分公式、参数与示例。

  • 「用时」不再附加口径说明：提交记录列表、提交详情统一只显示「用时」这一项。

v2.7.6#

  • 修复「一键更新」失败：个别网络环境下，更新源会返回"需要登录"的网页，旧版本把它当成源码包，只提示「不是有效的 ZIP 文件」。现在会识别出这不是更新包并自动换其它源，失败时给出可读原因。
  • 更新前先检查权限：只读部署（例如 systemd 的系统保护）会在下载之前就明确告诉你"请在服务器上用命令行更新"，不再下载解压一半才失败。
  • 更新过程可回滚：写入前自动快照，中途出错会把改过的文件全部还原，不会留下更新的半成品。
  • 重启更可靠：只结束本项目自己的服务进程（不会误杀其它程序），重启后会真实核实健康检查，不再出现"提示更新成功、其实还是旧版本"的情况。
  • 同时支持没有顶层目录的更新包；命令行 node deploy/update.js 与后台更新走同一套逻辑，失败原因与解决办法都会打印出来。

  • 版本号推进（维护性更新）：同步 package.json、Dockerfile、docker-compose.yml、部署文档与仓库说明里的版本标识，便于镜像标签与安装脚本对齐。
  • v2.7.4 的功能与界面保持不变（按钮/边框的主题一致性、弹窗表现统一、界面样式沿用 v2.6.3、Linux 部署修复均照旧）。

v2.7.4#

  • 按钮颜色与边框不再随主题变化：首页每日打卡、棕名（抄题解 / 作弊）、审核「通过」这几个按钮在所有主题下保持同一套颜色；所有按钮的边框颜色与粗细在任何主题下都与默认主题完全一致。
  • 弹窗表现统一：「编辑讨论」「设置用户权限」等弹窗在自定义主题下不再透出毛玻璃，与默认主题表现一致。
  • 界面样式回到 v2.6.3：按钮、标签、表格、卡片、描边、圆角与间距恢复成 v2.6.3 的样子；后台「用户管理」的操作按钮保留更紧凑的样式（一行放得下、不换行、文字不被截断）。
  • Linux 部署修复：默认监听 0.0.0.0，装完即可用服务器 IP 直接访问（修复"部署完成却打不开"）；非 root 绑定 80 端口时自动授予所需权限；systemd 使用 node 的绝对路径；防火墙按实际端口放行并提示云安全组；部署完成后自动做健康检查，失败会打印服务日志与排查清单，成功才提示访问地址；重置数据后会重建数据目录，避免服务起不来。

v2.7.3#

优化
